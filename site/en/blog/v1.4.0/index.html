1.4.0: three apps, separate connection profiles

Local Route Launcher now manages ChatGPT, Antigravity App and Antigravity IDE from one window. Each app keeps its own proxy host, port and installation path. The launcher passes those settings when opening a compatible app without changing the system proxy or DNS.

What changed

  • Separate settings and connection status for ChatGPT, Antigravity App and Antigravity IDE.
  • A three-card main window, plus macOS menu-bar and Windows system-tray controls after closing it.
  • Nine interface languages with system, light and dark appearance.
  • An update badge only when GitHub offers a newer stable release with an installer for your platform; clicking downloads it in your browser.

Get started

  1. Keep an HTTP or mixed proxy port you are authorized to use running.
  2. Choose a target app and save its proxy host, port and installation path.
  3. Fully quit the target app, then open it through the launcher; restart it after changing settings.
  4. After an actual app request, inspect proxy reachability, launch arguments and connection snapshots.

Compatibility and limits

Supports detectable compatible Electron builds on Apple Silicon Macs with macOS 13+, and Windows 10 22H2 / Windows 11 x64. Diagnostics are snapshots, not proof that all traffic uses the proxy or that an account or model works. The launcher does not provide a proxy service. Use only authorized networks and services in accordance with applicable laws and terms.

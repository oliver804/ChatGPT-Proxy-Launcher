如何给 ChatGPT 单独设置代理，不修改系统代理？

在 Local Route Launcher 中保存已有 HTTP 代理的地址和端口，完全退出 ChatGPT，再通过启动器打开。配置仅传给启动的兼容应用，不修改系统代理或 DNS。修改地址后需要重启 ChatGPT；启动器不提供网络接入服务。

为什么 Windows 安装包比 macOS DMG 大？

Windows 安装包自带 .NET 桌面运行环境，安装后无需另行下载运行库。macOS 版使用系统提供的 SwiftUI 和 AppKit 框架，因此安装包更小。

如何安装 Windows 版？

下载 x64 EXE 安装包，按提示为当前用户安装，无需另装 .NET。支持九种语言切换，关闭窗口后可从系统托盘访问。未自动找到应用时，请选择兼容的 ChatGPT.exe；受限制的商店安装包可能无法直接启动。适用于 Windows 10 22H2 / Windows 11 x64，暂不支持 ARM64。安装包未签名，可能显示 SmartScreen 提示，请核对 Release 来源和 SHA-256，并保持系统安全功能开启。

支持哪些 Mac 和 ChatGPT 版本？

当前支持 Apple Silicon（M 系列芯片）、macOS 13 及以上系统，以及可识别的 Electron 版 ChatGPT。不支持 Intel Mac 或旧版原生 ChatGPT。主窗口和菜单栏均可切换九种语言，即时生效并记住选择；macOS 自带菜单和系统对话框可能跟随系统语言。

需要已有的本地代理吗？

需要。启动器使用现有代理提供的 HTTP 或混合端口，不包含代理服务。请保持你有权使用的本地代理运行；路由效果取决于目标应用对参数的支持情况。当前不支持需要账号密码认证的代理。

所有 ChatGPT 流量都会经过代理吗？

不保证。它使用应用支持的代理机制，主要覆盖 Chromium 的 HTTP、HTTPS 和 WebSocket 请求。语音、WebRTC、UDP 及部分子进程可能不使用这些设置。连接检查只是即时快照，也不能证明全部流量都经过代理。

首次打开被 macOS 拦截怎么办？

安装包使用本地签名，尚未经过 Apple Developer ID 签名或公证。确认来自本项目的 GitHub 发布页面后，可在「系统设置 → 隐私与安全性」中允许打开，无需关闭 SIP 或系统安全检查。

会收集账号信息或聊天记录吗？

启动器不读取或保存 ChatGPT 密码、Cookie、令牌或聊天记录，也没有遥测或自动上传。配置保存在本机。连接检查会通过指定代理向 chatgpt.com 发起不附带账号凭据的 HEAD 请求。阅读隐私说明 ↗

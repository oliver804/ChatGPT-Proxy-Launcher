A FEW THINGS TO KNOW

A few good questions.

Something else on your mind?
Ask on GitHub ↗

How do I set a proxy for ChatGPT or Antigravity without changing my system proxy?

Choose the target app and save your existing HTTP proxy host, port and app path. Fully quit that app, then open it through the launcher. Each app has separate settings; system proxy and DNS stay unchanged. Restart the selected app after changes. The launcher does not provide a proxy service.

Why is the Windows installer larger than the macOS DMG?

The Windows installer bundles the .NET desktop runtime, so no separate runtime download is needed after installation. The macOS edition uses system-provided SwiftUI and AppKit frameworks, keeping its download smaller.

How do I install the Windows version?

Run the x64 EXE installer for your current user. The app bundles .NET, includes nine interface languages, and stays in the system tray when closed. Choose a compatible target-app EXE if automatic detection finds nothing. Windows builds are unsigned and may show SmartScreen; verify the release source and SHA-256, and keep system protections enabled. Follow your administrator’s installation policy.

Which platforms and target apps are supported?

Detectable compatible Electron builds of ChatGPT, Antigravity App and Antigravity IDE are supported on Apple Silicon Macs with macOS 13+, and Windows 10 22H2 / Windows 11 x64. Intel Macs, Windows ARM64 and older native ChatGPT builds are not supported; restricted Store packages may not permit direct launch. The main window and menu/tray panel offer nine interface languages.

Do I need an existing local proxy?

Yes. The launcher uses an existing HTTP or mixed proxy port; it does not provide a proxy service. Keep a proxy you are authorized to use running. Routing depends on the target application’s support for these settings. Proxies requiring username/password authentication are not supported.

Will all target-app traffic use the proxy?

That is not guaranteed. The launcher uses proxy mechanisms supported by compatible apps, primarily covering Chromium HTTP, HTTPS and WebSocket requests. Voice, WebRTC, UDP and some background processes may not follow these settings. Connection checks are snapshots and cannot prove that all traffic uses the proxy.

What if macOS blocks the app on first launch?

The app is ad-hoc signed, but is not Developer ID signed or notarized by Apple. After verifying that it came from this project’s GitHub release page, allow it in System Settings → Privacy & Security. You do not need to disable SIP or system security checks.

How do I configure Antigravity App and IDE separately?

Choose each app in the sidebar and save its own proxy host, port and installation path. Fully quit the app, then launch it through the launcher. The two profiles are separate from ChatGPT. Check background-service connections again after a real request.

How does the launcher notify me about updates?

An update badge appears only when GitHub has a newer stable release with an installer for your platform. Clicking downloads it in your default browser; you run the installer yourself. Offline or current versions show no badge.

Does it collect account details or conversations?

The launcher does not read or store target-app passwords, cookies, tokens or conversations. There is no telemetry or automatic upload, and settings stay on your computer. Connection checks send a credential-free HEAD request to the selected service through your proxy. Read the privacy policy ↗

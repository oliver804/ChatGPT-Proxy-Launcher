A FEW THINGS TO KNOW

A few good questions.

Something else on your mind?
Ask on GitHub ↗

How do I set a proxy for ChatGPT without changing my system proxy?

Save your existing HTTP proxy host and port in Local Route Launcher, fully quit ChatGPT, then open it through the launcher. Settings are passed to the compatible app without changing system proxy or DNS. Restart ChatGPT after changing the endpoint. The launcher does not provide a proxy service.

Why is the Windows installer larger than the macOS DMG?

The Windows installer bundles the .NET desktop runtime, so no separate runtime download is needed after installation. The macOS edition uses system-provided SwiftUI and AppKit frameworks, keeping its download smaller.

How do I install the Windows version?

Run the x64 EXE installer for your current user. The app bundles .NET, includes nine interface languages, and stays in the system tray when closed. Choose a compatible ChatGPT.exe if automatic detection finds nothing. Windows builds are unsigned and may show SmartScreen; verify the release source and SHA-256, and keep system protections enabled. Follow your administrator’s installation policy.

Which platforms and ChatGPT versions are supported?

macOS 13+ on Apple Silicon, or Windows 10 22H2 / Windows 11 on x64, with a detectable Electron version of ChatGPT. Intel Macs, Windows ARM64 and older native ChatGPT versions are not supported. Restricted Store packages may not permit direct launch. Switch among nine languages in the main window or menu panel. The choice is saved and takes effect immediately; macOS-owned menus and dialogs may follow the system language.

Do I need an existing local proxy?

Yes. The launcher uses an existing HTTP or mixed proxy port; it does not provide a proxy service. Keep a proxy you are authorized to use running. Routing depends on the target application’s support for these settings. Proxies requiring username/password authentication are not supported.

Will all ChatGPT traffic use the proxy?

That is not guaranteed. It uses app-supported proxy mechanisms, primarily covering Chromium HTTP, HTTPS, and WebSocket requests. Voice, WebRTC, UDP, and some child processes may not follow these settings. Connection checks are snapshots and cannot prove that all traffic uses the proxy.

What if macOS blocks the app on first launch?

The app is ad-hoc signed, but is not Developer ID signed or notarized by Apple. After verifying that it came from this project’s GitHub release page, allow it in System Settings → Privacy & Security. You do not need to disable SIP or system security checks.

Does it collect account details or conversations?

The launcher does not read or store ChatGPT passwords, cookies, tokens, or conversations. There is no telemetry or automatic upload, and settings stay on your computer. Connection checks send a HEAD request to chatgpt.com through your proxy, without account credentials. Read the privacy policy ↗

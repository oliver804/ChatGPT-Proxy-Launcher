A FEW THINGS TO KNOW

A few good questions.

Which Macs and ChatGPT versions are supported?

Apple Silicon Macs running macOS 13 or later, with a detectable Electron version of ChatGPT. Intel Macs and older native ChatGPT versions are not supported. The app UI is Chinese; project documentation is available in Chinese and English.

Do I still need to run Clash Verge?

Yes. The launcher uses an existing HTTP or mixed proxy port; it does not provide a proxy service. You can turn off TUN and system proxy features in your proxy app while keeping its local port available. The launcher does not change those settings. Proxies requiring username/password authentication are not supported.

Will all ChatGPT traffic use the proxy?

That is not guaranteed. It uses app-supported proxy mechanisms, primarily covering Chromium HTTP, HTTPS, and WebSocket requests. Voice, WebRTC, UDP, and some child processes may not follow these settings. Connection checks are snapshots and cannot prove that all traffic uses the proxy.

What if macOS blocks the app on first launch?

The app is ad-hoc signed, but is not Developer ID signed or notarized by Apple. After verifying that it came from this project’s GitHub release page, allow it in System Settings → Privacy & Security. You do not need to disable SIP or system security checks.

Does it collect account details or conversations?

The launcher does not read or store ChatGPT passwords, cookies, tokens, or conversations. There is no telemetry or automatic upload, and settings stay on your Mac. Connection checks send a HEAD request to chatgpt.com through your proxy, without account credentials. Read the privacy policy ↗

# Local Route Launcher for ChatGPT desktop apps now speaks nine languages

**Local Route Launcher v1.3.0** is available for macOS and Windows. It passes your existing local HTTP proxy settings when launching a compatible ChatGPT desktop app, without changing the system proxy or DNS.

Both the **macOS DMG** and **Windows EXE** now offer English, Simplified Chinese, Traditional Chinese, Russian, Persian, Belarusian, Spanish, Arabic, and Portuguese. The launcher remembers your choice and updates its window, menu bar or tray, errors, and connection report. Arabic and Persian use right-to-left layouts.

To use it, keep a proxy you are authorized to use running, save its host and port, fully quit ChatGPT, and reopen it through the launcher. Connection checks inspect proxy reachability, launch arguments, and a snapshot of TCP connections.

The release targets **macOS 13+ on Apple Silicon** and **Windows 10 22H2 / Windows 11 x64** with a detectable Electron-based ChatGPT installation. Older native builds, Intel Macs, Windows ARM64, and some restricted Store packages are not supported. A successful check does not prove every request uses the proxy or that account access works. No proxy service is included.

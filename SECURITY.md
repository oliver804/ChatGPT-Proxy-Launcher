# Security / 安全

## Supported version / 支持版本

The current public release, 1.0.0, receives fixes. / 当前公开版本 1.0.0 接收修复。

## Reporting / 报告问题

Send security issues privately to **Oliver**, [oliver804x@gmail.com](mailto:oliver804x@gmail.com).
Do not open a public issue with an exploit involving private accounts, credentials, company information, or internal network details. Include a sanitized description, affected version, expected behavior, and reproducible steps. No response-time guarantee is made.

安全问题请私下发送给 **Oliver**：[oliver804x@gmail.com](mailto:oliver804x@gmail.com)。不要在公开 Issue 中发布涉及私人账户、凭据、公司信息或内部网络的利用细节。请提供脱敏后的说明、受影响版本、预期行为和复现步骤；项目不承诺固定响应时限。

## Boundaries / 能力边界

This launcher configures supported proxy mechanisms; it does not enforce network isolation or intercept all protocols. Default packages are ad-hoc signed and not notarized. Review diagnostic reports before sharing them. Pattern-based repository checks reduce accidental disclosure but do not replace human review.

启动器配置受支持的代理机制，不提供强制网络隔离，也不拦截所有协议。默认安装包为 ad-hoc 签名，未公证。分享诊断报告前须检查内容。仓库中的模式扫描有助于减少意外泄露，但不能代替人工检查。

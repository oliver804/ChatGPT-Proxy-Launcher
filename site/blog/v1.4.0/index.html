1.4.0：一个启动器，三份独立配置

现在可以在同一个窗口管理 ChatGPT、Antigravity App 和 Antigravity IDE。每个应用分别保存代理地址、端口和安装路径，启动时传入对应设置，不修改系统代理或 DNS。

这次更新了什么

  • ChatGPT、Antigravity App、Antigravity IDE 各有独立配置和连接状态。
  • 主窗口保留三张功能卡片；关闭窗口后可从 macOS 菜单栏或 Windows 系统托盘操作。
  • 支持九种界面语言，以及跟随系统、浅色和深色外观。
  • 只在 GitHub 提供适用于当前平台的稳定新版时显示更新入口；点击后在浏览器下载安装包。

如何使用

  1. 保持你有权使用的 HTTP 或混合代理端口运行。
  2. 选择目标应用，保存代理地址、端口和安装路径。
  3. 完全退出目标应用，再通过启动器打开；修改配置后也需重新启动。
  4. 在应用产生实际请求后查看代理连通、启动参数和连接快照。

兼容性与边界

适用于 Apple Silicon Mac（macOS 13+）和 Windows 10 22H2 / Windows 11 x64 上可识别的兼容 Electron 版本。连接检查是即时快照，不能证明所有流量都经过代理，也不能证明账号或模型服务可用。启动器不提供代理服务；使用时请遵守适用法律、服务条款及网络授权。

如何给 ChatGPT 或 Antigravity 单独设置代理？

选择目标应用，保存已有 HTTP 代理的地址、端口和应用路径，完全退出该应用后通过启动器打开。各应用设置独立，不修改系统代理或 DNS。修改设置后需重新启动对应应用；启动器不提供网络接入服务。

为什么 Windows 安装包比 macOS DMG 大？

Windows 安装包自带 .NET 桌面运行环境，安装后无需另行下载运行库。macOS 版使用系统提供的 SwiftUI 和 AppKit 框架，因此安装包更小。

如何安装 Windows 版？

下载 x64 EXE 安装包，按提示为当前用户安装，无需另装 .NET。支持九种语言切换，关闭窗口后可从系统托盘访问。未自动找到目标应用时，请手动选择兼容的 EXE；受限制的商店安装包可能无法直接启动。适用于 Windows 10 22H2 / Windows 11 x64，暂不支持 ARM64。安装包未签名，可能显示 SmartScreen 提示，请核对 Release 来源和 SHA-256，并保持系统安全功能开启。

支持哪些系统和目标应用？

支持 Apple Silicon Mac（macOS 13 及以上）与 Windows 10 22H2 / Windows 11 x64 上可识别的兼容 Electron 版 ChatGPT、Antigravity App 和 Antigravity IDE。不支持 Intel Mac、Windows ARM64 或旧版原生 ChatGPT；受限制的商店安装包可能无法直接启动。主窗口与菜单栏 / 托盘支持九种界面语言。

需要已有的本地代理吗？

需要。启动器使用现有代理提供的 HTTP 或混合端口，不包含代理服务。请保持你有权使用的本地代理运行；路由效果取决于目标应用对参数的支持情况。当前不支持需要账号密码认证的代理。

目标应用的所有流量都会经过代理吗？

不保证。启动器使用兼容应用支持的代理机制，主要覆盖 Chromium 的 HTTP、HTTPS 和 WebSocket 请求。语音、WebRTC、UDP 及部分后台进程可能不使用这些设置。连接检查是即时快照，不能证明全部流量都经过代理。

首次打开被 macOS 拦截怎么办？

安装包使用本地签名，尚未经过 Apple Developer ID 签名或公证。确认来自本项目的 GitHub 发布页面后，可在「系统设置 → 隐私与安全性」中允许打开，无需关闭 SIP 或系统安全检查。

Antigravity App 和 IDE 如何分别设置代理？

在左侧选择对应应用，各自保存代理地址、端口和安装路径。完全退出后从启动器打开。两份配置与 ChatGPT 独立；后台服务需要实际请求后再次查看连接快照。

启动器如何提醒更新？会自动安装吗？

仅当 GitHub 发布了适用于当前平台的稳定新版，版本旁才显示“有更新”。点击后在默认浏览器下载安装包，安装仍需自行完成。离线或无新版时不显示。

会收集账号信息或聊天记录吗？

启动器不读取或保存目标应用的密码、Cookie、令牌或聊天记录，也没有遥测或自动上传。配置保存在本机。连接检查会通过指定代理向对应服务站点发起不附带账号凭据的 HEAD 请求。阅读隐私说明 ↗
